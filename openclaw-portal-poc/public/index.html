Why agents weren't appearing in Chat — now fixed

The Chat dropdown reads from ~/.openclaw/openclaw.json → agents.list. Creating a folder under ~/.openclaw/agents/ is not enough — the agent must also be registered in that JSON config. This portal now patches openclaw.json automatically and restarts the gateway so new agents appear immediately in Chat. For your existing agents (AgentPDF, AppDeveloper, etc.) — click Register in Config on each one.

How to chat with your agent (after registering)

1

For existing agents (AgentPDF, AppDeveloper, etc.) — click Register in Config button on each one above. This writes them into openclaw.json and restarts the gateway.

2

Wait ~5 seconds for gateway to restart, then refresh the OpenClaw dashboard in your browser.

3

Go to Chat → click the agent name dropdown (top-left, shows "main") → your agents should now appear there.

4

Select your agent → start chatting. The badge IN CONFIG ✓ in the agent list above confirms it's registered.

5

To confirm: open localhost:3000/api/debug and check configAgentsList — that's exactly what Chat reads.
