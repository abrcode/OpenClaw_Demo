⚠️
Important: These credentials are stored in portal-config.json — a separate file from openclaw.json. OpenClaw rejects unknown keys in openclaw.json and aborts the gateway. The portal reads from its own config file so your gateway keeps running normally.

Gmail / Google OAuth
Not configured
1. console.cloud.google.com/apis/credentials
2. Create → OAuth 2.0 Client ID → Web application
3. Authorised redirect URI:
  http://localhost:3000/api/oauth/google/callback
4. Enable Gmail API in API Library
Scope: gmail.readonly gmail.send userinfo.email
